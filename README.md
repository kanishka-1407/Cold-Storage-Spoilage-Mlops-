## Problem Description

The project focuses on predicting the percentage of crop spoilage in cold storage facilities using Machine Learning. It uses storage conditions such as temperature, humidity, storage duration, power cuts, crop type, and chamber details to estimate spoilage.

## Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- DVC (Data Version Control)
- MLflow
- FastAPI
- Docker
- Kubernetes
- GitHub Actions

## Project Objective

To build an end-to-end MLOps pipeline that predicts crop spoilage, monitors data drift, retrains models, and deploys the best-performing model through an API.
